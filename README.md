| `materi.html` | Lab Siklus Hormon (P7 digital), 7 topik, Mitos atau Fakta, Evaluasi 12 soal |

| `ar.html` | Meja AR: Hormon Siklus, Mekanisme Persalinan, Involusi Uterus, Refleks Menyusui |

## Publikasi di GitHub Pages
1. Buat repository baru (Public), mis. `garba-fisiologi`.
2. **Add file → Upload files** → pilih **semua berkas** (semuanya ada di satu folder, tanpa subfolder) → **Commit changes**.
3. **Settings → Pages** → Branch **main** / **(root)** → **Save**. Tunggu 1–2 menit.

## Mengganti nama asisten AI
Buka `data.js`, ubah baris `namaAI: "Bunda Lidia"`.

## AI daring (opsional)
Tanpa kunci API aplikasi berjalan dalam mode offline. Untuk Gemini: buat kunci di https://aistudio.google.com/apikey lalu tempel di menu ⚙️ AI.
